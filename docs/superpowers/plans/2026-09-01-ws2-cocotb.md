## Global Constraints

- `COCOTB=1` is strictly opt-in: with `COCOTB=0` (default) the VCS compile/run command lines contain **no** cocotb artifacts and the smoke test still passes.
- cocotb pinned `==1.9.2`; installed via the venv flow (lock regenerated PYTHONPATH-clean per `ci/setup-venv.sh`'s established pattern).
- VCS access for cocotb comes ONLY from `+vpi -P dv/uvm/core_ibex/cocotb_pli.tab -load $(cocotb-config --lib-name-path vpi vcs)`; the tab contains exactly `acc+=rw,wn:*`. Never add `-debug_access` flags (stock compile already carries `+pp`/`+f`).
- All SV additions live under `` `ifdef COCOTB_SIM `` (files may be unconditionally listed in `ibex_dv.f`; their contents compile away when the define is absent).
- Dead-cocotb watchdog: if Python has not set the alive bit by 100ns, the sim `$fatal`s with a clear message (a Python import error must fail in nanoseconds, not hang a license). (Spec amended to `$fatal` by recorded ruling — fail loud, never a clean `$finish`.)
- Flow environment values are substituted CONCRETELY at metadata/command-construction time — commands go through `shlex.split()` + `subprocess.run()` with no shell, so `$VAR` strings never expand (`scripts/riscvdv_interface.py:132`, `scripts/scripts_lib.py:77`). Never put `$PYTHONPATH`-style references into command/env strings.
- Test-module selection is a first-class knob: `COCOTB_MODULE` (Makefile var, default `dv.cocotb.ibex_cocotb`), carried through metadata; stimulus parameterization uses simv plusargs (readable via `cocotb.plusargs`) — both documented in TB_CONTRACT.md. This is the spec's two-level selection, delivered in WS2.
- Seeds: SV gets `+ntb_random_seed=<seed>` (existing); cocotb gets `RANDOM_SEED=<seed>` env var — same seed value, recorded together.
- Site rules from WS1 (binding): `module` exits 1 on success; poll logs directly, never park on notifications; `( cd dv/uvm/core_ibex && ... )` subshells; `REPO=$(git rev-parse --show-toplevel)`; never commit `out*/`; commits end with `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.
- Reference patterns (read-only): quasar `tb/sv/quasar_cocotb_if.sv`, `tb/env/quasar_cocotb_monitor.sv`, `tb/quasar_cocotb.py`; ws-tensix `src/t6ifc/vcs-core/CMakeLists.txt` + `catch_dead_cctb.sv`; cite what you borrow in one-line comments only where non-obvious.
