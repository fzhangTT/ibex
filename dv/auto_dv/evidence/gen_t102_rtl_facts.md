## 5. What this note does not decide

Comparator behaviour for R1/R2 and the shim legalisation for R3..R8 are tb-infra's (T-102); this note gives the
RTL values and their timing so the T-102 response can cite verified lines. The Critic's attribution
(gen_critic_batch1_v1.md section 2) is consistent with every row above; rows R1 and R2 add the ID-done timing
argument (special_req -> DECODE retain -> FLUSH), rows R4..R7 the field-by-field values, reset values and the
bit sets that read zero.
