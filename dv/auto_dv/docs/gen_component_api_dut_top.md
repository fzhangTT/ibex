# Component API: gen_dut_top (DUT wrapper) and the DUT RTL filelist

Owner: tb-infra. Build configuration: `opentitan` (ibex_configs.yaml:41-61). Files:
`dv/auto_dv/tb/gen_dut_top.sv`, `dv/auto_dv/tb/gen_rtl.f` (generated by
`dv/auto_dv/tb/gen_filelist.py`), `dv/auto_dv/tb/gen_tb_pkg.sv`, `dv/auto_dv/tb/gen_smoke_tb_top.sv`
and `gen_smoke_tb.f` (compile smoke only, not the TB top). Compile evidence:
`dv/auto_dv/evidence/gen_t005_compile_log_excerpt.md`. Pre-execution review:
`dv/auto_dv/reviews/2026-09-03-claude-plan-gen_tb_scoping_notes.md` (APPROVE-WITH-CHANGES, all
changes applied here).

## 1. What gen_dut_top is

The DUT by owner ruling (DV_prompt.txt Section 2): `ibex_core` plus `ibex_register_file_ff`,
wired together as `rtl/ibex_top.sv:437-448, 534-560` does, with every remaining `ibex_core` port
exposed exactly as `ibex_core` declares it. Nothing else is inside: no clock gate, no lockstep
core, no `ibex_trvk`, no cache RAMs, no scramble-key logic (all `ibex_top` equipment, out of
scope or supplied by the TB).

Instance names (fixed; the coverage `-cm_hier` file and the binds home use them):
`u_ibex_core`, `u_register_file`.

## 2. Parameters

The wrapper declares the 14 `-pvalue+` names of `util/ibex_config.py opentitan vcs_opts`
verbatim (`RV32E, BranchTargetALU, WritebackStage, ICache, ICacheECC, ICacheScramble,
BranchPredictor, DbgTriggerEn, SecureIbex, PMPEnable, PMPGranularity, PMPNumRegions,
MHPMCounterNum, MHPMCounterWidth`) and the five enum parameters (`BaseIsa, RV32M, RV32B, RV32ZC,
RegFile`) whose defaults come from the config's `+define+` macros with `ifndef` fallbacks
(pattern: examples/simple_system/rtl/ibex_simple_system.sv:9-12, 59-62). `-pvalue+` only reaches
the compile top, so the TB top (or the smoke top) re-declares the same names and forwards them.

Derived as localparams with the same conditional expressions as `rtl/ibex_top.sv:41-45, 212-227`
(never as constants; the `ibex_core` defaults are the non-ECC widths and would mis-size the
icache RAM and bus ports):

| Derived | Value under opentitan | Rule |
|---|---|---|
| MemECC | 1 | `= SecureIbex` |
| MemDataWidth | 39 | `MemECC ? 32 + 7 : 32` |
| DummyInstructions | 1 | `= SecureIbex` |
| ICacheTweakInfection | 1 | `= SecureIbex` |
| BusSizeECC | 39 | `ICacheECC ? BUS_SIZE + IC_DATA_ECC_SIZE : BUS_SIZE` |
| LineSizeECC | 78 | `BusSizeECC * IC_LINE_BEATS` |
| TagSizeECC | 28 | `ICacheECC ? IC_TAG_SIZE + IC_TAG_ECC_SIZE : IC_TAG_SIZE` |
| RegFileDataWidth | 32 | `RegFileECC ? 32 + 7 : 32` |
| RegFileCapEccWidth | 35 (REGCAP_W) | `RegFileECC ? REGCAP_W + 7 : REGCAP_W` |

Decisions taken as a parameter or define so an owner answer is a one-line change (each is
printed in the time-0 config banner):

| Knob | Default | Why this default | Pending question |
|---|---|---|---|
| `RegFileECC` (parameter) | 0 | mirrors `ibex_top.sv:215`; the RF ECC check lives only in the out-of-scope lockstep core. With 1 the cap zero word would also need its 64/57 SECDED encoding (not derived) | rtl-arch Q-A |
| `ResetAll` (parameter) | `SecureIbex` (=1) | mirrors `ibex_top.sv:212-213`; avoids X into coverage sampling | rtl-arch Q-B |
| `+define+RVFI` (compile define) | on | the retirement trace is the ISA-model comparison point (DV_prompt Section 7) | rtl-arch Q-C |
| `+define+GEN_DUT_SPLIT_INTG` (compile define) | off | off = bus ports exactly as `ibex_core` declares them, integrity in bits `[MemDataWidth-1:32]` (literal to the Section 2 ruling, review finding 1); on = ibex_top-style `data[31:0]` + `intg[6:0]` ports, pure bit-slicing (`ibex_top.sv:355-366, 861-869`) | tb-infra Q-1 |
| clock gate | none | `ibex_top` equipment; core runs on `clk_i`, `core_busy_o` exposed; `mcycle` therefore counts during WFI | tb-infra Q-2 |
| `DbgHwBreakNum`, `Dm*Addr`, `RndCnst*`, `CsrMvendorId/MimpId`, `PMPRst*` | ibex_core defaults | the values `ibex_top` passes | none |

`ICacheScramble` is accepted (so the config command applies unchanged) but forwarded nowhere: it
is not an `ibex_core` parameter; it only selects `ibex_top`'s RAM primitive. A generate-scope
`$fatal` (an elaboration system task) rejects any `RegFile` other than `RegFileFF` (only the FF
file is in scope).

## 3. Ports

Everything from `rtl/ibex_core.sv:61-190` except the register-file seam, nothing else.

| Group | Ports | Notes |
|---|---|---|
| Clock/reset/id | `clk_i`, `rst_ni`, `hart_id_i[31:0]`, `boot_addr_i[31:0]` | first fetch `{boot_addr_i[31:8], 8'h80}` (rtl/ibex_if_stage.sv:243) |
| Instruction bus | `instr_req_o`, `instr_gnt_i`, `instr_rvalid_i`, `instr_addr_o[31:0]`, `instr_rdata_i[MemDataWidth-1:0]`, `instr_err_i` | integrity bits are `instr_rdata_i[38:32]`; with `GEN_DUT_SPLIT_INTG`: `instr_rdata_i[31:0]` + `instr_rdata_intg_i[6:0]` |
| Data bus | `data_req_o`, `data_gnt_i`, `data_rvalid_i`, `data_we_o`, `data_be_o[3:0]`, `data_addr_o[31:0]`, `data_wdata_o[MemDataWidth-1:0]`, `data_tag_o`, `data_rdata_i[MemDataWidth-1:0]`, `data_tag_i`, `data_err_i` | with `GEN_DUT_SPLIT_INTG`: `data_wdata_o[31:0]` + `data_wdata_intg_o[6:0]`, `data_rdata_i[31:0]` + `data_rdata_intg_i[6:0]`. `data_tag_*` are CHERIoT residue: TB drives `data_tag_i=0`, expects `data_tag_o==0` |
| Cache RAMs | `ic_tag_req_o[1:0]`, `ic_tag_write_o`, `ic_tag_addr_o[7:0]`, `ic_tag_wdata_o[27:0]`, `ic_tag_rdata_i[27:0][2]`, `ic_data_req_o[1:0]`, `ic_data_write_o`, `ic_data_addr_o[7:0]`, `ic_data_wdata_o[77:0]`, `ic_data_rdata_i[77:0][2]`, `ic_scr_key_valid_i`, `ic_scr_key_req_o` | TB test equipment answers these: synchronous RAM, read data the cycle after `req`; `ic_scr_key_req_o` is a one-cycle pulse |
| Interrupts | `irq_software_i`, `irq_timer_i`, `irq_external_i`, `irq_fast_i[14:0]`, `irq_nm_i`, `irq_pending_o` | levels; `irq_pending_o = \|(pins & mie)` combinational |
| Debug/diag | `debug_req_i`, `crash_dump_o` (crash_dump_t), `double_fault_seen_o` | |
| RVFI | all `rvfi_*` of `rtl/ibex_core.sv:136-181` | only with `+define+RVFI` |
| Control/alerts | `fetch_enable_i`, `mcounteren_writable_i` (ibex_mubi_t), `alert_minor_o`, `alert_major_internal_o`, `alert_major_bus_o`, `core_busy_o` (ibex_mubi_t) | exactly `IbexMuBiOn` enables; any other value is off, no alert |

Internal tie-offs: `cheriot_enable_i = IbexMuBiOff` on the core and the register file (Section 2
ruling); the register file's `test_en_i = 1'b0` (unused by the FF implementation,
`rtl/ibex_register_file_ff.sv:232-233`).

## 4. Wave-level behaviour the wrapper adds

None. The wrapper is wiring only: the optional integrity split is bit concatenation, the banner
is an `initial` `$display`, the `RegFile` guard is a generate-scope elaboration `$fatal`. There is no
logic in the DUT hierarchy beyond `ibex_core` and `ibex_register_file_ff`, so the coverage scope
is `+tree <tb_top>.<dut>.u_ibex_core` and `+tree <tb_top>.<dut>.u_register_file`.

## 5. Config banner

At time 0 the wrapper prints one line per parameter value, each starting with
`gen_tb_pkg::GEN_BANNER_TAG` (`GEN_CONFIG_BANNER`), plus `build_config=<name>` taken from the
plusarg `+gen_build_config=<name>` (`gen_tb_pkg::PLUSARG_BUILD_CONFIG`; `UNSPECIFIED` when
absent), the LFSR seed and permutation (`RndCnstLfsrSeed`, `RndCnstLfsrPerm`, which select the
dummy-instruction sequence), and a line naming the PMP reset parameters as ibex_core defaults.
A log scanner greps the one tag. Example: `dv/auto_dv/evidence/gen_t029_smoke_red_runs.md`.

## 5a. Smoke contract (gen_smoke_tb_top, compile/elaboration proof only)

`gen_smoke_tb_top` is the T-005/T-010 compile-and-run proof, not a regression-tier test (the real
TB top replaces it; it carries no coverage expectation and no mutation evidence beyond the red
runs below). Its pass/fail contract, for the Runtime Manager's log scanner:

| Token / knob | Meaning |
|---|---|
| `GEN_SMOKE_PASS` | printed once after the bounded run when both checks held; the ONLY pass token |
| `GEN_SMOKE_FAIL: no RVFI retirement observed` | `$fatal` (collected as a fatal) when no `rvfi_valid` was seen in the run |
| `GEN_SMOKE_FAIL: <n> alert cycles observed` | `$fatal` when any of `alert_minor_o`, `alert_major_internal_o`, `alert_major_bus_o` was high in any cycle |
| `gen_smoke_tb_top requires +define+RVFI` | time-0 `$fatal` when compiled without `+define+RVFI` (vacuous-pass guard) |
| `+gen_smoke_cycles=<n>` (`PLUSARG_SMOKE_CYCLES`) | post-reset cycles before the checks run (default 3000); `1` is the red run of the retirement check |
| `+gen_smoke_intg_flip=<bit>` (`PLUSARG_SMOKE_INTG_FLIP`) | flips one bit of the TB-side SECDED NOP word: the red run of the alert check (`alert_major_bus_o` on the first consumed fetch) |
| `GEN_SMOKE: ...` | informational lines (max_cycles, boot address, final counts); never a verdict |

Pass/fail is decided from the tokens and the collected fatal, never from the exit code (SIM_RECIPE
Section 5). Red-run evidence for both `$fatal` checks: `dv/auto_dv/evidence/gen_t029_smoke_red_runs.md`.

## 6. Filelist recipe

`dv/auto_dv/tb/gen_rtl.f` is generated, never hand-edited:

```
bash -lc 'source ci/env.sh && python3 dv/auto_dv/tb/gen_filelist.py'          # regenerate
bash -lc 'source ci/env.sh && python3 dv/auto_dv/tb/gen_filelist.py --check'  # CI drift check
```

The script runs `fusesoc --cores-root . run --setup --no-export --tool=vcs --target=default
lowrisc:ibex:ibex_core`, rewrites the emitted `.scr` to clone-root-relative paths (run vcs from
the clone root), substitutes `prim_generic` for the two `prim_xilinx` files the default target
picks (`prim_clock_gating.sv`, `prim_flop.sv`; neither is instantiated below `ibex_core`, so the
choice is harmless and made for consistency), and appends `rtl/ibex_register_file_ff.sv` (the
second DUT module, listed only in `ibex_top.core`). The list carries the two include directories
the RTL needs (`vendor/lowrisc_ip/ip/prim/rtl` for `prim_assert.sv`,
`vendor/lowrisc_ip/dv/sv/dv_utils` for `dv_fcov_macros.svh`; the latter is an include-path
dependency only, nothing is built on it). Defines are not in the list: the compile command adds
`+define+RVFI` and the config output. `rtl/ibex_core.f` is stale (eight files missing) and is
not used. TB files go in a second `-f` list (`gen_smoke_tb.f` for the smoke).

## 7. Decisions recorded from the T-005 pre-execution review (APPROVE-WITH-CHANGES)

| Finding | Decision as built |
|---|---|
| 1 (medium) integrity ports | Ports literal to the Section 2 ruling: `instr_rdata_i`, `data_rdata_i`, `data_wdata_o` are `MemDataWidth` wide with integrity in `[38:32]`. The split lives in the TB bus interface. `+define+GEN_DUT_SPLIT_INTG` is the one-line switch if the owner answers Q-1 "split". |
| 2 (low) `test_en_i` | Tied `1'b0` inside `gen_dut_top`; not a wrapper port. Scoping notes (Q-3 withdrawn) and rtl-arch's gen_param_resolution.md now say the same. |
| 3 (low) derived widths | `BusSizeECC`, `TagSizeECC`, `LineSizeECC`, `MemDataWidth`, `RegFileDataWidth`, `RegFileCapEccWidth` are localparams with `ibex_top`'s conditional expressions (Section 2 table). Cite corrected to `ibex_top.sv:45`. |
| 4 (low) fusesoc caveat | Scoped to `prim_clock_gating.sv` and `prim_flop.sv`; substitution kept for consistency (Section 6). |
| 5 (low) split cite | `ibex_top.sv:861-869` (Section 2 table). |
| 6 (low) smoke scope | `gen_smoke_tb_top` is pure SV: config banner, legal idle drive, NOP program, bounded `$finish`; no cocotb, no UVM environment (UVM only linked). The cocotb/VPI wiring of SIM_RECIPE Section 4 is proven in T-010 by the Runtime Manager. |
| 7 (info) `ICacheScramble` | Declared and accepted so the unchanged config command elaborates. VCS X-2025.06-SP2 emitted no unused-parameter warning for it (evidence file Section 2); had it, the class would be accepted. |
