[Medium][dv/auto_dv/docs/gen_test_plan.md:438] The boundary inference is stated as "the retiring instruction fetched by that lookup reveals the lookup tag through its RVFI pc_rdata", but the row never says how a lookup (visible to the TB only as a read of all ways at index i, `ic_tag_addr_o`) is associated with a retiring instruction, and that association is the whole difficulty. The prefetcher runs sequential lookups ahead of retirement (`prefetch_addr_q`, `:220-224`), several lookups at the same index can be in flight, and the TB does not know which lookups were squashed (`branch_i` is `prefetch_branch`, internal to `ibex_if_stage.sv:313`). Two cases the stated blind spot misses: (a) a squashed sequential lookup at index i (line A+1) followed by a redirect to a target B with the same index i but a different tag: an "oldest unresolved lookup at this index" match attributes tag(B) to the A+1 lookup, and if way w held A+1 valid the DUT correctly pulses while the judge, holding tag(B), rules "none owed" and fails the run; the squashed lookup is not "unjudged", it is misjudged, and the real B lookup is then orphaned; (b) a lookup consumed only by the upper half of a 32-bit instruction that straddles the line boundary (pc index i-1, `IC_LINE_BYTES = 8`) followed by a taken branch: no retiring pc_rdata has index i, so the lookup goes unjudged for a reason that is not squashing, although pc_rdata plus the instruction length would reveal it. The "none otherwise" half is a new stricter check that half 1 does not cover (half 1 accepts any pulse within the window of an announced injection), so a mis-association is a false failure in a measured run. - State the association rule in the WP-12 row (e.g. reconstruct the lookup address stream as sequential runs of lines from each RVFI control-flow discontinuity, match lookups to it in order, and report any ambiguous parse, not only squashed lookups, as unjudged with no cp_alert_pulses sample and no failure), extend the blind-spot sentence to cover ambiguous same-index parses and the straddling upper half, and say that the probe cross-check in evidence runs is what bounds the inference's mis-association rate (the "why acceptable" the High asked for).
