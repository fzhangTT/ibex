- [Major][dv/auto_dv/stim/gen_riscv_dv_target/riscv_core_setting.sv:1, testlist.yaml:1, user_extension/*:1] Five new files carry no `gen_` prefix. - [Medium][dv/auto_dv/stim/gen_elf2mem.py:12-14,111] The read-back digest is `sum32 + count` over word values only, so it is address-independent by construction. A memory model that recomputes it over its own contents cannot detect the failure modes a backdoor load actually has: wrong base (byte- vs word-index confusion), a run placed at the wrong offset, or two runs swapped. The docstring also states the SV memory model "recomputes both after `$readmemh` and fatals on mismatch" as fact, but no such model is committed yet. - Fold the word index into the digest (for example a CRC32 or sum over `(idx, word)` pairs) and word the docstring as the requirement the future memory model must meet.

- [Minor][dv/auto_dv/stim/gen_riscv_dv_target/gen_link.ld:16-17] DM origin/length and PROG origin/length re-type `gen_dut_top.sv:61-64` and `gen_tb_pkg.sv:15` plus a 1 MiB window that has no SV home (magic-numbers rubric).
