## Findings

[Medium][dv/auto_dv/env/gen_fcov_pkg.sv:1025] `ut_mv_miss_expected = n_mv_miss;` copies the whole run counter, not the self-test's own contribution. The self-test runs after the program has retired (`gen_ut_isa_cov.py` waits for the retire count first, then calls FCOV_SELFTEST), so any real miss counted during the program in a unit-test run is absorbed into the exclusion and the referee at `:1036` can never fire in those five runs. Today the ut runs happen to have 0 real misses (3 or 5 sampled, 1 miss, 1 excluded), so nothing is hidden, but the exclusion is wrong by construction - use `ut_mv_miss_expected += n_mv_miss - miss0;` (or `+= 1`) so only the vector's own miss is excluded.
